
PROJECT NAME: Team Task Board

PHASE: Phase 1 - Procedural Programming

DESCRIPTION:
A menu-driven Python application used to manage
team tasks, assign members, track deadlines,
and manage task dependencies.

FEATURES:
1. Add New Task
2. Update Task Status
3. View All Tasks
4. View Blocked Tasks
5. View Overdue Tasks
6. Exit

TECHNOLOGIES:
- Python 3
- Command Line Interface

CONCEPTS USED:
- Functions
- Loops
- Conditional Statements
- Lists and Dictionaries
- Modules
- Exception Handling
- Date Handling

HOW TO RUN:
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run: python main.py


MAIN OPERATIONS:
1. Add Task: create a task with a team member, due date and dependency.
2. Update Task Status: change a task to Pending, In Progress or Completed. A blocked task cannot be started or completed.
3. Identify Blocked and Overdue Work: view all tasks, blocked tasks, or overdue tasks.

NOTE:
Tasks are stored temporarily and are lost
when the program is closed.
